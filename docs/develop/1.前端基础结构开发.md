## 页面布局

### 页面清单

| 页面 | 标识 | 职责 |
|------|------|------|----------|
| 探索 | P-MAP | 主工作区：地图、Agent、需求输入入口 |
| 行程 | P-TRIP | 时间表与地图路线双视图、节点编辑、冲突提示 |
| 我的 | P-MINE | 偏好分析、收藏的地点、账号管理、设置页面 |

### 导航结构

```text
[P-AUTH]
   => 登录成功 => [P-MAP]（默认首页，底部主导航）

顶部主导航（三个入口）
   ├── [P-MAP]    探索
   ├── [P-TRIP]   行程
   └── [P-MINE]   我的
```

> 注：主导航在全局范围内保持一致，用户可在三个主页面之间自由切换。

## 探索页面开发

### 前置任务

- 先生成发布版安全码SHA1、调试版安全码SHA1和 PackageName ，PackageName 为 com.savorseek.app ，用于申请高德 SDK APIkey
- 然后让我完成 高德SDK 的引入
- 完成以上前置任务后才能开始进行下面的正式任务

### 正式任务

- 页面主体为全屏地图区域
- 地图使用高德SDK的瓦片，可以自由单指拖拽、双指缩放
- 页面底部固定显示一个 Agent 交互栏
- Agent 交互栏用于输入用户需求（类似指令栏），本项目不采用传统对话式交互，而是让用户像队长一样指挥一支拟人化的 Agent 小队来实现自己的需求
- 地图始终作为页面的主要展示内容，占据除底部交互栏外的全部可用空间
- 底部 Agent 交互栏固定在页面底部，不随地图滚动而消失
